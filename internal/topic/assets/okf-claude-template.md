# TOPIC_TITLE

**Topic scope:** portable Open Knowledge Format bundle for `TOPIC_DOMAIN`.

**Domain:** `TOPIC_DOMAIN`

This topic is an OKF bundle, not an LLM-wiki research lab. Concepts live as typed markdown files at the bundle root for the MVP, with standard markdown links and YAML frontmatter.

## Bundle contract

- Every concept markdown file has `type`, `title`, `description`, and `timestamp` frontmatter.
- `index.md` is generated by `kb` and groups concepts by type.
- `log.md` records bundle updates using ISO date headings.
- Links should be relative markdown links so the bundle renders in GitHub and other markdown tools.

## Operations

- Promote a wiki concept into this bundle with `kb promote <wiki-doc> --to TOPIC_SLUG --type <Type>`.
- Check conformance with `kb okf check TOPIC_SLUG`.
