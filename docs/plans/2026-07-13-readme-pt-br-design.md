# README em português do Brasil — Design

## Objetivo

Disponibilizar documentação principal completa em português brasileiro sem
substituir o README em inglês, que permanece como idioma padrão do projeto.

## Abordagem aprovada

- Criar `README.pt-BR.md` como tradução completa do `README.md` atual.
- Incluir um seletor `English | Português (Brasil)` no topo dos dois arquivos.
- Manter comandos, flags, caminhos, nomes de arquivos, variáveis de ambiente e
  blocos de código inalterados.
- Traduzir títulos, explicações, tabelas e mensagens editoriais para pt-BR.
- Preservar e traduzir as seções introduzidas no fork: dependências por
  capacidade, providers de URL e Whisper local.

## Manutenção

Mudanças de produto devem atualizar os dois READMEs no mesmo pull request.
O inglês é a fonte de referência para comandos e exemplos executáveis.
